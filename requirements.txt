# What Vercel installs into the serverless function.
#
# PyPI packages only. Our own code is NOT listed here: it reaches the function
# as source, via `includeFiles` in vercel.json, and api/index.py puts server/
# on sys.path.
#
# That indirection is not a preference, it is a constraint. A local path
# requirement (`./server`) makes Vercel's installer -- uv -- derive the package
# name from the directory and then reject the build, because the directory is
# called `server` and the distribution is called `kaigyou-support`:
#
#     x Failed to build `server @ file:///vercel/path0/server`
#     `-> Package metadata name `kaigyou-support` does not match given name `server`
#
# Keep this file to published packages and the problem cannot come back.
