直前の調査結果を、指定された JSON スキーマに写してください。

**これは書き写す作業です。新しい事実を足さないでください。**

## 規則

- `sources` は、**検索結果に実際に出てきた URL** だけ。下に「今回の検索で
  取得した URL」の一覧を付けてあります。**この一覧に無い URL は保存されずに
  落とされます。**
- `name` は入力の医院名をそのまま。書き換えないでください。
- **確認できなかった項目は出さないでください。** `not_confirmed` に、何が
  確認できなかったかを書いてください。**空にしないでください**——何もかも
  確認できた医院は、まずありません。
- `products` と `segments` は下の語彙から。当てはまる語が無ければ空にする。
- `place_confirmed` は、**確認できたものだけ**をキーで列挙してください
  （下の語彙の `place_attributes` の `key`）。書いていないものは入れない。
  「駐車場：不明」のような行は作らないでください。
- `map_x` / `map_y` は -2 〜 +2。**判定根拠が弱ければ `map_placed` を false**
  にして、`map_basis` に理由を書いてください。0 は「どちらとも言えない」と
  判定できた場合であって、判定できなかった場合ではありません。
- 価格は、**サイトに書いてあった数字だけ**。相場や推定を書かないでください。
